    HOW IT WORKS

    ビットで見ると、
    仕組みはシンプル。

    ワイルドカードマスクの 0 は入力アドレスと一致、1 は0でも1でもよいことを表します。マスク 0.0.0.12 の末尾は2進数で 00001100。この2つのビットを切り替えると、末尾が0・4・8・12の4アドレスになります。

    00001100 可変ビット

    CiscoのACLと同じビット単位の一致判定です。入力アドレスのうち、マスクが0のビットを保持し、1のビットをすべての組み合わせに展開します。

    ＊ Wildcard Calculator入力データは送信されません。計算はお使いのブラウザ内で完結します。IPv4 only
